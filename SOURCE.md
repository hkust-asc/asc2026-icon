# Source

This repository is an ASC Team study fork. It is not an official ASC Committee repository, and it is not a university endorsement.

- Contest: ASC26 (2026)
- Upstream: https://github.com/ASC-Competition/ASC26-icon
- This fork: https://github.com/hkust-asc/asc2026-icon

## What is in this fork

Official committee copy of the ICON model tree plus an ASC26 test case under `testcase/`. The repository root has no README. Additional official final test cases (visualization, without validation) are published separately at https://doi.org/10.17617/3.7zmpyb and are not included in this fork.

## Copyright and license

The repository root does not declare a GitHub license. The bundled `icon-model/README.md` states that ICON is available under a BSD 3-clause license and points to `icon-model/LICENSES/` and `icon-model/AUTHORS.TXT`. This fork does not change those terms.
